# 📌 Overview

The **Car Rental Project** is a modern web application designed to simplify the process of renting cars online. Users can browse available vehicles, explore car details, and make bookings through a clean and responsive interface.

This project focuses on:

* 🚘 Smooth car browsing experience
* 📱 Fully responsive UI
* ⚡ Fast and interactive frontend
* 🔐 User-friendly booking flow
* 🎨 Clean and modern design

---

# ✨ Features

## 👤 User Features

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Prithvi1666/CarRental-Project.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd CarRental-Project
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Start the Development Server

```bash
npm run dev
```
